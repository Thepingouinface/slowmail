Ce que vous tapez ici ne quitte pas votre ordinateur

Cette page n'envoie rien à personne : elle est réglée pour que son code ne puisse faire aucune requête réseau, et elle ne mémorise rien (si vous fermez l'onglet, le formulaire est vidé). Vous pouvez le vérifier : coupez votre connexion Internet une fois la page chargée, elle continue de fonctionner. Son code est lisible dans generateur.js.

Le fichier produit contient vos mots de passe : gardez-le pour vous. Docker n'est pas encore installé ? C'est l'étape 1 du tutoriel.

Cette page n'est pas complète

Le modèle du fichier n'a pas été inclus (page ouverte sans passer par la construction du site). Utilisez la méthode à la main du tutoriel.

1Le mot de passe de SlowMail

Celui que vous taperez pour entrer dans SlowMail. Choisissez-en un nouveau, long (une phrase fait très bien l'affaire), jamais utilisé ailleurs.

(20 signes tirés au hasard dans votre navigateur : notez-le).

2Votre messagerie

Le compte qui enverra vos mails. Les mots de passe ne servent qu'à remplir le fichier ci-contre.

Les réglages sont dans l'aide de votre hébergeur (cherchez « paramètres SMTP » ou « serveur sortant »). Plus de détails dans le tutoriel. Seul OVH a été essayé : si le premier envoi de test échoue, l'erreur du serveur s'affiche dans SlowMail.

Le plus souvent l'adresse complète.

Celui de votre messagerie, pas celui de SlowMail. Si vous préférez ne pas le taper sur une page web, laissez vide : vous l'écrirez dans le fichier (une seule ligne).

L'adresse qui apparaît comme expéditeur : celle de la boîte, ou une adresse que votre hébergeur vous autorise à utiliser.

Où arrivent les réponses. Laissez vide pour les recevoir à l'adresse d'expédition.

Réglages avancés (facultatif)

8080 convient presque toujours. Changez-le seulement si un autre programme l'utilise déjà (SlowMail s'ouvrira alors à http://localhost: suivi de ce port).

Aperçu du fichier

Il se met à jour pendant que vous tapez. Les mots de passe sont masqués ici, mais présents dans le fichier téléchargé.

Fichier téléchargé

Il s'appelle docker-compose.yml et se trouve dans le dossier de téléchargement de votre navigateur (le plus souvent « Téléchargements »).

Il manque encore le mot de passe de la boîte mail

Vous l'avez laissé vide. Ouvrez le fichier avec un éditeur de texte et écrivez-le entre les guillemets de la ligne MAIL_PASSWORD. Si ce mot de passe contient le signe $, écrivez-le deux fois ($$).

Votre port n'est pas 8080

SlowMail s'ouvrira à l'adresse http://localhost:.

Et maintenant ?

  1. Rangez le fichier dans un dossier slowmail : l'étape 2 du tutoriel donne les commandes pour votre système.
  2. Démarrez SlowMail avec docker compose up -d : l'étape 4.
